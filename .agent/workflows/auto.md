// turbo-all

The following steps are pre-approved for autonomous execution to speed up development.

## 1. Synchronize with GitHub
1. Add all changes: `git add .`
2. Commit changes: `git commit -m "Automated update via Antigravity"`
3. Push to main: `git push origin main`

## 2. Environment Maintenance
1. Install dependencies: `npm install` or `pip install -r requirements.txt`
2. Clean temporary files: `rm -rf tmp/*`

## 3. Execution & Testing
1. Run main application: `python main.py`
2. Run scheduler scripts: `node scheduler/scripts/[script_name].js`
3. Running verification tests.
